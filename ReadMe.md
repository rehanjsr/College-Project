# AI Financial Assistant

## What it does
Personal finance tracker that analyses spending patterns, 
predicts future expenses, and detects unusual transactions.

## Tech Stack
Python, PostgreSQL, pandas, numpy, matplotlib, scikit-learn, psycopg2

## Features (current)
- Categorical spending analysis
- Expense trend visualisation  
- Monthly spending breakdown
- Anomaly detection (in progress)
- Spending prediction ML model (in progress)

## Features (planned)
- Natural language transaction input via AI
- Flask web dashboard
